# Titanic Survival Prediction

A machine learning project based on the famous [Titanic dataset](https://www.kaggle.com/c/titanic).  
The goal is to predict passenger survival using data analysis, feature engineering, and machine learning models.

---

## Project Overview
- Exploratory data analysis (EDA) of passenger demographics and survival rates  
- Data preprocessing and feature engineering (handling missing values, encoding, scaling)  
- Training and evaluation of multiple ML models  
- Comparison of accuracy scores to find the best approach  

---

## Tech Stack
- Python 3.13.7  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn
